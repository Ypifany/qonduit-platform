# Qonduit

Qonduit helps RMF and GRC professionals practice constructing and revising a truthful representation of a system before reducing it to compliance requirements.

## Current experience

The homepage contains **See the System You Already Live In**, a guided home-system mapping experience.

Learners:

1. Describe what they need their home to do.
2. Connect home technology to that purpose.
3. Identify people, devices, services, and outside dependencies.
4. Receive an editable starting map.
5. Save Version 1.
6. Investigate a relevant new question selected from their answers.
7. Revise the map into Version 2 and reflect on what changed.

There is no score or model answer. The learner's changing system representation is the primary artifact.

## Privacy and storage

- No account is required.
- No personal map data is sent to a server.
- No analytics or external JavaScript libraries are used.
- Work is not autosaved.
- Learners must download the PNG map or editable Qonduit JSON project before closing or refreshing the page.

## Files

- `index.html` — guided home-system experience
- `styles.css` — visual and responsive design
- `app.js` — guided flow, map editing, Version 1 and Version 2 logic, and downloads
- `operations-situation-map.html` — preserved earlier Operations Situation Map prototype

The site is buildless and can be published directly with GitHub Pages.
